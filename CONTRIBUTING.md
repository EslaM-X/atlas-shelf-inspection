# Contributing

Thanks for considering a contribution.

## Guidelines

1. **Additive only.** Contributions should not modify existing behavior.
2. **Evidence-backed.** Every claim needs a committed artifact.
3. **Tested.** Run the existing test suites before submitting.
4. **Documented.** If you add a feature, document it.

## Pull Requests

- Use descriptive titles
- Reference related issues
- Include screenshots or evidence where applicable
- Ensure CI passes

## Code of Conduct

Be respectful. Be constructive. Be professional.
